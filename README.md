# SILENCED — дуэльный 3D-шутер для Telegram

Дуэль один на один от первого лица. Пистолет с глушителем, упрощённая
физика частей тела (руки/ноги отстреливаются, юнит переключается на
другую руку или начинает хромать), кровь и лужи, боты в стиле
"Continental" (чёрные костюмы, разные противники), настоящий счётчик
"онлайн" и "сыграно дуэлей" через WebSocket.

## Структура проекта

```
gunduel/
├── public/
│   ├── index.html     — интерфейс, стили, экран меню/HUD/результата
│   └── game.js         — вся 3D-логика (Three.js): сцена, боты, физика, кровь
├── server.js            — Node.js сервер: раздаёт статику + WebSocket-счётчики
├── package.json
└── README.md
```

## 1. Заливаем на GitHub

```bash
cd gunduel
git init
git add .
git commit -m "SILENCED: дуэльный шутер"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<название-репо>.git
git push -u origin main
```

## 2. Деплой на Render

1. Зайдите на https://render.com → **New +** → **Web Service**.
2. Подключите ваш GitHub-репозиторий.
3. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free (для старта достаточно)
4. Нажмите **Create Web Service** — Render выдаст адрес вида
   `https://silenced-duel.onrender.com`.

Игра сразу доступна по этому адресу в обычном браузере (мобильном и
десктопном) — можно проверить прицеливание и стрельбу до подключения
к Telegram.

> Счётчик "сыграно дуэлей" хранится в оперативной памяти процесса.
> На бесплатном плане Render "усыпляет" сервис при простое, и после
> пробуждения счётчик обнулится. Если нужно, чтобы счётчик пережил
> перезапуски — подключите Render Disk или внешнее хранилище (Redis,
> Postgres) и замените `STATE.played` в `server.js` на чтение/запись
> туда.

## 3. Подключаем как Telegram Mini App

1. В Telegram откройте **@BotFather** → `/newbot`, создайте бота (если ещё нет).
2. Команда `/newapp` (или `/mybots` → выбрать бота → **Bot Settings** →
   **Menu Button** / **Web App**).
3. В качестве URL укажите ваш адрес с Render:
   `https://silenced-duel.onrender.com`
4. Задайте название и иконку — игра уже подстраивается под тему и
   безопасные отступы Telegram (через `telegram-web-app.js`, уже
   подключён в `index.html`).
5. Готово — кнопка меню бота открывает игру внутри Telegram.

## Управление

- **Прицеливание**: провести пальцем/мышью по экрану.
- **Выстрел**: кнопка "ОГОНЬ" справа снизу (или пробел на десктопе).
- Попадание в руку → персонаж переключается стрелять другой рукой.
- Попадание в обе руки → выстрелить нельзя.
- Попадание в ногу → соперник шатается/хромает, у игрока начинается тряска камеры.
- Попадание в голову/корпус → мгновенная победа/поражение.

## Что можно доработать дальше

- Полноценный физический движок (например `cannon-es` или `ammo.js`)
  для настоящего ragdoll вместо упрощённого падения частей.
- Более детальные модели персонажей (сейчас — стилизованные примитивы
  Three.js в силуэте "чёрный костюм", без использования реальных
  лицензированных образов).
- PvP через WebRTC/WebSocket (сейчас соперники — боты; текущий сервер
  уже умеет считать общих онлайн-игроков, что является основой для
  будущего матчмейкинга).
- Постоянное хранилище для статистики (см. раздел про Render Disk выше).
